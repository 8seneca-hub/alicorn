Provenance

Every token below is lifted verbatim from src/renderer/src/assets/main.css or derived from it by a stated rule. Nothing is invented. Type, radius and elevation follow docs/STYLEGUIDE.md. Dark is promoted to :root because the product is dark-first; the light set is carried as [data-theme="light"].

The brand has no hue at all. On a surface whose entire job is surfacing what needs a human, an accent colour competes with the signal — so the accent is white, and the primary action is a white button on near-black.

Colour discipline, stated as a rule the whole system obeys: the product is black and white, and exactly one hue exists in it. Amber means "a human is required" and nothing else ever uses it. Red survives only for destructive and failed states, where convention is load-bearing. Everything else — live, idle, success, identity, navigation — is monochrome and carries its meaning by shape and text, which the accessibility pass already required.
