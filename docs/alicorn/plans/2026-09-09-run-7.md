and catch what it missed. **Run `pnpm test config/scripts` in full before merging anything** — the
four-gate sweep is not enough, and it is what let all three of the above onto `main`.

### Why a whole-tree codemod can run alongside four other branches

CLAUDE.md's warning is that a _piecemeal_ rename makes the CI grep gate lie — not that no other work
may proceed. The measured conflict surface says the rest of this batch is safe:

- **`cloud/**` contains zero `ORCA_*` identifiers.** The control plane was Alicorn-branded from its
  first commit, so slots 2–4's server-side work cannot collide with the codemod at all.
- The desktop halves of IV1, PS1 and RB1-Task-4 are new files and small edits; git conflicts need
  overlapping _lines_, and a rename of an unrelated identifier is not one.

**R4 merges first regardless of finishing order**, and the other four rebase onto it. Any new code in
this batch names `ALICORN_*` and reads the legacy name through `readAlicornEnv` — a bare `ORCA_*` in a
new file now fails `verify:rebrand-env-gate`, which is the point of having seeded it last run.

**Three things the run taught, worth carrying to run 8.**

- **The four-gate sweep still is not enough, and neither is a green suite read in
  aggregate.** R4's full run showed 134 failures. Re-running the 41 failing files on a quiet
  machine and again against a `main` baseline split them: 14 files were real R4 regressions, the
  rest were pre-existing or load flakes. _Aggregate counts are not a verdict — diff the failing
  file set against `main` before believing either number._
- **A test that scrubs an env name must scrub both spellings**, and this machine proves why: the
  session runs inside an Orca pane, so ambient `ORCA_*` is set. That is what surfaced R4's one real
  production defect — `codex-real-home-path.ts` renamed a read without its legacy fallback, so a
  pane from the previous release made Orca's own managed home look like a user's custom override.
- **The env gate caught its own author twice.** Both fixes for the above first reached for a literal
  `ORCA_*`; the gate refused them, and they now derive the legacy spelling through
  `withLegacyEnvKeys`. An earlier attempt to reach an empty baseline by allowlisting two whole
  release workflows was refused by the gate's own ratchet test — the same shape as run 6's R3
  repair, one run later.

**R5 is now unblocked** and is the next thing in the rebrand: R4 was the last ticket before the cut.
