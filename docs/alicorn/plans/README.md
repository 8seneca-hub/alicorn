## Conventions every plan shares

- Header, Global Constraints, Decisions, File structure, numbered `### Task N (<Plane key>)` headings
  (the `task-brief` script extracts by number), ≤ 2 ew per task, one commit per task, no AI
  attribution in commits.
- Shared files between owners follow the [OWNERSHIP.md](../OWNERSHIP.md) rule: additive one-liners,
  the second to land rebases; a plan that needs a line in the other owner's file says so in the task.
- Cloud tests run against Postgres when `ALICORN_TEST_POSTGRES_URL` is set; renderer strings are
  localised by tooling; anything written to the Ledger goes through the outbox.
